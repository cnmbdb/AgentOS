# AgentOS 项目章程

## 项目愿景

让开发者、站长和企业像安装插件一样创建、连接并运营 AI Agent。

## 产品定位

AgentOS 不是通用聊天页面，而是 AI Agent 业务运行平台：统一连接消息渠道、模型、知识库、业务工具和自动化工作流。

## 首批目标用户

- Telegram 机器人开发者
- WordPress 与独立站站长
- Shopify 商家
- 需要 AI 客服和自动化的中小企业

## 核心价值

1. 一个 Agent 可发布到多个渠道。
2. 业务能力通过权限明确的插件安装。
3. Agent 可调用 n8n 和第三方 API 完成实际任务。
4. 用户可自行选择模型供应商并控制成本。

## 成功标准

MVP 上线后，用户能在 10 分钟内完成：注册、创建 Agent、绑定 Telegram、添加知识、完成首次有效对话。

## 阶段里程碑

- M0：仓库、架构、开发规范建立
- M1：身份、租户、Agent CRUD
- M2：Web Chat 与 Telegram 消息闭环
- M3：知识库与工具调用
- M4：配额、计费与可观测性
- M5：首个公开测试版本
