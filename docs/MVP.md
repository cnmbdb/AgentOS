# AgentOS MVP 范围

## 必须完成

- 邮箱登录与租户初始化
- Agent 创建、编辑、启停和删除
- 模型供应商配置与基础模型路由
- Web Chat
- Telegram Bot Webhook
- 文本/Markdown/PDF 知识导入
- 基础 RAG 检索
- HTTP Tool 与 n8n Workflow Tool
- 会话日志、调用量与错误日志
- 基础套餐配额和限流

## 暂缓

- Discord、WhatsApp、微信、Slack
- 可视化工作流编辑器
- 插件交易市场
- 多 Agent 协作
- 企业 SSO
- 私有化安装器

## 验收闭环

用户创建一个“商品客服 Agent”，上传商品文档，绑定 Telegram，并能够准确回答商品问题和调用测试订单查询 Tool。
